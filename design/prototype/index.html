Wrangler prototype

Superseded. This was the first design prototype, kept for its Tune drawer. The real app now runs in a browser with sample photos: cd apps/desktop && pnpm dev, then open /?demo.

Everything here is live: every key, slider and field drives one shared state, so the channel screens, thumbnails, names, meter and Run label all update together. Open Tune (top right) to adjust material, screens, keys, type and colour, then copy the values. Photos are AI-generated samples; sizes are estimates.

From the file manager

Right-click images or folders in Finder, Explorer, Dolphin or Nautilus and pick a pinned recipe. A small unit runs it, shows where the files went and what was saved, with Undo one press away. "Open in Wrangler…" loads them into the main window instead.
